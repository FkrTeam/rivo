# RIVO — corporate website

Architectural millwork. **rhythm, built.**

Vite 8 (Rolldown) · vanilla ES modules · three.js · GSAP + ScrollTrigger · WebP.
No framework, no Tailwind, one persistent WebGL canvas.

## Run

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production build -> dist/
npm run preview    # serve dist/ at http://localhost:4173
```

Asset pipeline:

```bash
npm run assets:panel    # rebuild public/assets/models/panel.glb from src/webgl/panelSpec.js
npm run assets:images   # assets-src/images/*.{jpg,png,tif,webp} -> public/assets/images/*.webp + manifest
npm run index:notebook  # NotebookLM photos -> assets-src/images/<slug>-NN (NN = the notebook's number) + src/data/notebook-index.json; add -- --prune to drop files the notebook no longer has
npm run check:framing   # (panel wall only) print where the wall lands on screen per pose and aspect
```

## Concept

The page is a drawing sheet cut by one gesture from the identity's graphic
language (rivo.pdf, 08 / Graphic Language): the **V-cut**, a directional crop at
the slant of the wordmark's "v" (19 degrees off vertical). Left of the cut the
sheet is plain ink and carries the copy; right of the cut runs a field of
**laths** parallel to the cut, each separated by a measured reveal (two hairlines
with ink between), every fifth reveal doubled so the field reads as panel modules
made of slats rather than as stripes. Daylight falls from the top right. The
layer is fixed, so the page scrolls over it and the cut never moves.

The hero's datum line ("Precision should feel effortless.") is a leader that runs
from the copy to the cut, and the RIVO Red **dot** marks the point where it
lands.

Inside the cut the hero plays a **slider** of project frames (`src/data/hero.js`:
260 Washington / Belleville, 301 Washington / Hoboken, 1404 Willow / Hoboken).
The frames occupy only the region right of the cut foot, so the photograph is
spent on what is visible. A new frame is not faded in but cut in: a wipe
parallel to the cut sweeps it across, then it settles from a slight enlargement
(`src/ui/slider.js`, CSS keyframes, one timer). The caption top right carries the
index, the address and a RIVO Red progress bar. Autoplay pauses while the tab is
hidden or the hero is out of view, and is off under `prefers-reduced-motion`.
No WebGL, no animation library on the homepage.

**Projects** are one data file, `src/data/projects.js`. The homepage shows the
featured ones as aligned title-block cards (one shared 3:2 figure crop, no
stagger) with a "More projects" bar; `projects.html` lists all of them, and
`projects/<slug>.html` is a detail page per project: summary, title block,
photographs as plates on the 12-column sheet (landscape 7 columns, portrait 5,
the first one full width) and previous / next links. The list and detail pages
are generated by `scripts/build-pages.mjs` (`npm run pages`, run automatically
before `dev` and `build`) so their content is in the markup; they load
`src/page.js` for the shared chrome.

`/studio.html` is a separate demo page (light theme, placeholder copy) that
still uses the WebGL block composition in `src/blocks/`; the RIVO homepage does
not load it.

## Architecture

```
index.html                 semantic content, first paint
projects.html, projects/   generated project list + detail pages (npm run pages)
src/main.js                shell: styles, nav, project rendering, the datum, the hero slider
src/page.js                shell for the generated pages (styles, nav, year)
src/styles/                base (tokens, font, V-cut background, frame) · typography · layout · components
src/ui/                    navigation, projects (title-block sheets), interactions, datum (leader + dot on the cut), slider (hero frames)
src/data/                  assets.js (registry), images.js (manifest lookup), hero.js (slider frames), projects.js (all projects), content.js, images.manifest.json
src/blocks/                WebGL block composition engine, used by studio.html only
src/studio/                the light-theme demo page (studio.html, main.js, styles.css)
src/webgl/, src/animation/ the retired panel-wall experience (kept for reference, not imported)
scripts/                   build-pages.mjs · build-panel-glb.mjs · optimize-images.mjs · frame-check.mjs (panel wall only)
public/assets/             brand/ (wordmark, Inter) · models/ · textures/ · images/
```

## V-cut tokens

`--cut` (slant, 19deg), `--cut-foot` (where the cut meets the bottom of the
viewport: 50vw, 36vw on narrow screens), `--lath` (lath pitch, `clamp(44px, 4vw,
76px)`), `--gap` (the reveal, 6px / 4px), `--module` (laths per module, 5). The
field and its edge are one pseudo element rotated by `--cut` about the cut foot,
so the lath pattern is a plain vertical stripe that the rotation carries into
alignment with the cut. `src/ui/datum.js` reads the live tokens, solves where
the cut crosses the datum height and pins the dot there; it re-runs on resize.

## Performance

- No flash of unstyled content: the stylesheet (`src/styles/site.css`) is linked
  from `<head>` on every page, an inline rule paints the ink ground before it
  arrives, and the homepage cards are prerendered into index.html by
  `npm run pages`. Page-to-page navigation cross-fades where the browser
  supports view transitions.
- Homepage JavaScript: navigation, project rendering, the datum, the slider.
  About 9 kB, no three.js, no GSAP.
- Hero frames: WebP at 800 / 1400 / 2000 px plus the intrinsic width, chosen by
  `srcset`; the first frame decodes synchronously and loads with high priority.
- The background is one fixed layer with two CSS gradients on a rotated pseudo
  element. No images.
- Reduced motion: the reveal transitions collapse to 0.01 ms (see base.css).

## Adding real content

**Projects** — `src/data/projects.js`. Put photography in `assets-src/images/<slug>-NN.jpg`, run `npm run assets:images`, list the names in `gallery` (with alt text), pick a `cover`, write the `summary`, set `featured` for the homepage, then `npm run pages`. Source photography for the current projects is in `Downloads/RIVO-PROJECTS`. Locations are left empty where the project folder gives none; nothing else about a project is asserted beyond what its photographs show.

**Hero frames** — `src/data/hero.js`. Same pipeline; frames are picked by their NotebookLM names: `npm run index:notebook` copies the notebook's photographs into `assets-src/images/<slug>-NN` with the notebook's own numbers (it numbers each folder's photographs in ASCII order, from the `website/` subfolder where there is one), so 1404-WILLOW-HOBOKEN-6 is `1404-willow-hoboken-06`; `focus` is the `object-position` used for the cover crop, `HERO_INTERVAL` / `HERO_WIPE` set the timing. In DEV, `window.__rivo.slider.stop()` / `.show(i)` hold or pick a frame for review.

**KTX2 finish textures** — produce with KTX-Software (`ktx create … --encode uastc`) into `public/assets/textures/`, register in `ASSETS.textures` with `group: 'materials'`.

**GLB** — `panel.glb` is generated. If a Draco or Meshopt compressed model is introduced, register the decoder in `AssetManager.js`.
